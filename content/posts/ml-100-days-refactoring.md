## 專案起源與動機

過去曾參與「100 天機器學習馬拉松」，雖然走完了流程，但在實作細節與系統架構上仍有許多可以優化的空間。隨著近期取得 AWS Certified Machine Learning – Specialty 認證，我決定重新審視這份專案，不再侷限於單純的 Jupyter Notebook 腳本，而是以「系統工程師」的視角進行全面重構。

## 三個月重構目標

本次計畫預計分為三個核心階段：

1. **盤點與演算法重構 (Weeks 1-4)**
   - 導入 AI 輔助開發工具（如 Cursor / Claude）加速舊有程式碼的解析與清理。
   - 將鬆散的腳本重構為具備物件導向 (OOP) 與模組化的高品質 Python 程式碼。

2. **模型 API 化與系統封裝 (Weeks 5-8)**
   - 採用 FastAPI 將核心預測模型封裝為 RESTful API。
   - 撰寫 Dockerfile 進行容器化，確保執行環境的一致性。

3. **AWS 雲端佈署與架構優化 (Weeks 9-12)**
   - 將容器化後的模型佈署至 AWS 雲端環境。
   - 評估並實作高可用性 (HA) 架構，確保 API 服務的穩定運作。

## 預期成果

這不僅是一次機器學習理論的複習，更是將「資料科學」與「後端系統架構」結合的實戰紀錄。後續的技術筆記與重構過程，將會持續更新於此專案紀錄中。
